# 📊 Sales Performance Analysis Dashboard

### Excel | Data Analysis | Business Intelligence

---

## 📌 Project Overview

This project focuses on analyzing sales performance using Microsoft Excel. The dashboard provides an interactive view of sales data, helping explore business performance and identify meaningful trends.

## 🎯 Project Objectives

- Analyze overall sales performance.
- Monitor key performance indicators (KPIs).
- Identify sales trends and patterns.
- Compare sales performance across different categories.
- Present insights through interactive dashboards.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Excel Formulas

## 📈 Dashboard

The dashboard provides a visual summary of sales performance through KPI cards, charts, and interactive filters.

## 📊 Key Performance Indicators

- Total Sales
- Total Profit
- Total Quantity
- Total Transactions

## ⚙️ How to Use

1. Download the Excel dashboard file.
2. Open it using Microsoft Excel.
3. Navigate through the dashboard.
4. Use available slicers and filters to explore sales performance.

## 📚 Key Learning

- Data analysis using Excel.
- Creating interactive dashboards.
- Working with Pivot Tables and Pivot Charts.
- Building KPI-based reports.
- Presenting business insights visually.
